<objective>
Last.fm top-tracks API and BridgePlaylistBuilder: the data pipeline that converts a list of bridge artist names into a list of playable MediaItems.

Purpose: This is the core resolution engine for Phase 5. A completed bridge path is just artist names — this plan resolves each artist to ranked tracks via Last.fm, then fuzzy-matches each track to a YT Music video ID. Failed matches are silently skipped (PLAY-04).

Output: `LastFM.getArtistTopTracks()` method, `ArtistTopTracksResponse` model, `BridgePlaylistBuilder` class with unit tests.
</objective>
