## Color

All colors via `MaterialTheme.colorScheme.*` — do not hardcode hex values. The theme is dynamic (Material You wallpaper colors on Android 12+, materialKolor seed on older). Default seed: `Color(0xFFED5564)` (rose-red).

| Role | M3 Token | Usage |
|------|----------|-------|
| Dominant (60%) | `colorScheme.background` | Screen background behind the sheet |
| Secondary (30%) | `colorScheme.surface` / `colorScheme.surfaceVariant` | Bottom sheet background, default node card background |
| Accent (10%) | `colorScheme.primary` | Now-playing node left border (4dp), now-playing node background tint (primary at 12% alpha), genre tag container color |
| Connector line | `colorScheme.outline` at 0.38f alpha | Vertical line segment between adjacent path nodes |
| Listener count | `colorScheme.onSurface` at 0.60f alpha | De-emphasized secondary text in each node |
| Sheet drag handle | `colorScheme.onSurfaceVariant` at 0.40f alpha | Drag handle indicator bar at top of sheet (Material 3 default) |

Accent reserved for: now-playing node left border (4dp wide), now-playing node background tint, genre chip container fill. Nowhere else in this phase.

Source: `06-CONTEXT.md` D-05 (now-playing highlight), `<specifics>` section (colored left border / background tint recommendation). Consistent with Phase 4 color contract.

## Interaction Contract

### Bottom Sheet: Appearance and Dismissal

**Bottom sheet implementation:** Use the project's custom `BottomSheet` composable from `ui/component/BottomSheet.kt` (not `ModalBottomSheet`) — this matches the player and queue sheet patterns already in the codebase and supports the two-anchor collapsed/expanded model.

**`rememberBottomSheetState` parameters:**
- `dismissedBound`: `0.dp`
- `collapsedBound`: `220.dp` (peek height — shows seed node, two bridge nodes, and the beginning of a third, signaling more content below)
- `expandedBound`: `BoxWithConstraints` parent height minus top inset

**Trigger:** When `BridgeUiState` transitions to `PathFound` or `PlaylistReady`, automatically expand the sheet to `collapsedBound` using `LaunchedEffect(uiState)` + `state.collapseTo()` (spring-animated via `BottomSheetAnimationSpec`).

**Dismiss:** User can drag the sheet down past `collapsedBound` to dismiss (i.e., sheet hides). Sheet can be re-shown by tapping a "Show Path" affordance (see Copywriting). The sheet is NOT a modal blocker — search inputs on the BridgeScreen behind it remain accessible when the sheet is collapsed.

**Back gesture:** `BackHandler(enabled = state.isExpanded)` collapses the sheet to `collapsedBound` before dismissing.

Source: `06-CONTEXT.md` D-01, D-02. Custom `BottomSheet` pattern from `ui/player/Player.kt` queue sheet (lines 631-648).

### Path Node List

**Layout — vertical column inside a `LazyColumn`:**

```
BottomSheet (collapsedBound=220dp, expandedBound=parent)
  Column (fillMaxWidth, padding horizontal 16dp)
    SheetDragHandle (centered, 32dp wide x 4dp tall, rounded, colorScheme.onSurfaceVariant at 0.40f)
    Spacer (8dp)
    Text("Bridge Path", titleMedium, colorScheme.onSurface)
    Spacer (16dp)  // lg token
    LazyColumn (verticalArrangement = Arrangement.spacedBy(0dp))
      items(path) { index, artist ->
        PathNodeRow(artist, isNowPlaying = index == nowPlayingIndex)
        if (index < path.lastIndex) VerticalConnectorLine()
```

**`PathNodeRow` internal layout:**

```
Row (fillMaxWidth, verticalAlignment = Top)
  // Now-playing left border
  Box(width=4dp, fillMaxHeight, background = if isNowPlaying primary else Transparent)
  // Node content
  Column(
    modifier = Modifier
      .fillMaxWidth()
      .background(if isNowPlaying primary.copy(0.12f) else Transparent)
      .padding(horizontal=16dp, vertical=8dp),  // md + sm tokens
    verticalArrangement = spacedBy(4dp)  // xs token
  )
    Row(verticalAlignment=CenterVertically, horizontalArrangement=spacedBy(4dp))
      Text(artist.name, titleSmall, colorScheme.onSurface)
      // Now-playing icon — only visible when isNowPlaying
      AnimatedVisibility(isNowPlaying) {
        Icon(Icons.Outlined.VolumeUp, 16dp, tint=colorScheme.primary)
      }
    Text(formatListeners(artist.listenerCount), bodySmall, colorScheme.onSurface at 0.60f)
    // Genre tags — only shown when tags list is non-empty
    FlowRow(horizontalArrangement=spacedBy(4dp), verticalArrangement=spacedBy(4dp))
      artist.tags.take(3).forEach { tag ->
        GenreTagChip(tag)
```

**`GenreTagChip` spec:**
- Material 3 `SuggestionChip` with `border = null`
- Container color: `colorScheme.primary` at 0.12f alpha
- Label color: `colorScheme.primary`
- Label style: `labelMedium`
- Height: 24dp (compact, below standard chip minimum — use `Modifier.height(24.dp)` with `contentPadding = PaddingValues(horizontal=8.dp, vertical=0.dp)`)
- Non-interactive (no click handler — tapping a genre tag does nothing in this phase)

**`VerticalConnectorLine` spec:**
- `Box(width=4dp, height=12dp)` centered horizontally aligned with the node left border column
- Background: `colorScheme.outline` at 0.38f alpha
- Placed between every adjacent pair of nodes

**Now-playing indicator animation:**
- `animateColorAsState(targetValue = if isNowPlaying ... else Transparent, animationSpec = tween(300))` for both the left border color and the background tint
- `AnimatedVisibility(visible = isNowPlaying, enter = fadeIn(tween(200)), exit = fadeOut(tween(200)))` for the `VolumeUp` icon

Source: `06-CONTEXT.md` D-03, D-05, `<specifics>`. `animateColorAsState` pattern from `ui/component/NewMenuComponents.kt` lines 54-60.

### Now-Playing Highlight Update

When `BridgeUiState.PlaylistReady(path, nowPlayingIndex)` updates `nowPlayingIndex`, the list does not auto-scroll. The highlight animates in-place on the changing node. Auto-scroll is a v2 enhancement — not in this phase.

The `nowPlayingIndex` is derived in `BridgeViewModel` by matching `PlayerConnection.currentSong` artist name against the `path` list. String match is case-insensitive, trimmed. When no match is found, `nowPlayingIndex` remains at the last known value (no highlight clears mid-playback for transient mismatches).

Source: `06-CONTEXT.md` D-05, `<canonical_refs>` PlayerConnection.

### Listener Count Formatting

Format `listenerCount: Long` in the ViewModel before exposing to UI:
- `< 1,000`: render as-is (e.g. "847 listeners")
- `1,000–999,999`: divide by 1000, round to 1 decimal, append "K" (e.g. "142.3K listeners")
- `>= 1,000,000`: divide by 1,000,000, round to 1 decimal, append "M" (e.g. "1.2M listeners")

Format string template: `"{value} listeners"` — string resource key `bridge_path_listener_count` (new).

Source: `06-CONTEXT.md` D-04 (Last.fm `listeners` field).

### Layout Structure (BridgeScreen integration)

Phase 4 established the `BridgeScreen` outer structure. Phase 6 wraps it in a `Box` with the `BottomSheet` layered on top:

```
Box(fillMaxSize) {
  // Phase 4 content (search inputs, progress, error) inside Column
  BridgeSearchContent(uiState, viewModel)

  // Phase 6 overlay — only rendered when path exists
  if (uiState is PathFound || uiState is PlaylistReady) {
    BottomSheet(
      state = pathSheetState,
      onDismiss = { /* allow — sheet can be re-opened */ },
      collapsedContent = { PathSheetHandle() },
      content = { PathNodeList(path, nowPlayingIndex) }
    )
  }
}
```

The `BottomSheet` composable from `ui/component/BottomSheet.kt` renders a scrim behind it when expanded via its `background` lambda — set that to `Box(Modifier.background(Color.Black.copy(0.32f)))` for the expanded-sheet overlay.

Source: `06-CONTEXT.md` D-01, D-02. `BridgeScreen.kt` `when (uiState)` structure.

## Accessibility Contract

- Each `PathNodeRow` must have `Modifier.semantics { contentDescription = "${artist.name}, ${formatListeners(artist.listenerCount)}, genres: ${artist.tags.joinToString()}" }` so TalkBack reads the full node in one announcement.
- The now-playing `VolumeUp` icon must be `Modifier.semantics { contentDescription = "Now playing" }` — not empty.
- Genre tag chips must have `enabled = false` with `Modifier.semantics { disabled() }` since they are non-interactive — TalkBack will not announce them as buttons.
- The drag handle area must have `Modifier.semantics { contentDescription = "Bridge path sheet, drag to expand or collapse" }`.
- The animated now-playing left border is a purely visual decorator — mark it `Modifier.semantics { invisibleToUser() }`.
