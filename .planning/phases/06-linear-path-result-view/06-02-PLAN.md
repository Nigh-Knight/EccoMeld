**Part A: Create PathSheet.kt** (`app/src/main/kotlin/com/metrolist/music/ui/screens/bridge/PathSheet.kt`)

Per D-01, D-03, D-05, and the UI-SPEC interaction contract:

1. `PathSheet` composable:
   - Parameters: `path: List<String>`, `artistMetadata: Map<String, BridgeArtistInfo>`, `nowPlayingIndex: Int`, `modifier: Modifier = Modifier`
   - Layout: `Column(fillMaxWidth, padding horizontal 16.dp)`:
     - Drag handle: centered `Box(width=32.dp, height=4.dp, RoundedCornerShape(2.dp))` with `colorScheme.onSurfaceVariant.copy(alpha=0.4f)` background. Add `Modifier.semantics { contentDescription = "Bridge path sheet, drag to expand or collapse" }`
     - `Spacer(8.dp)`
     - `Text(stringResource(R.string.bridge_path_sheet_title), style = titleMedium, color = colorScheme.onSurface)`
     - `Spacer(16.dp)`
     - `LazyColumn(verticalArrangement = Arrangement.spacedBy(0.dp))`:
       - `itemsIndexed(path) { index, artistName ->` (use `itemsIndexed` from `androidx.compose.foundation.lazy`)
         - `val info = artistMetadata[artistName]`
         - `val isNowPlaying = index == nowPlayingIndex`
         - `PathNodeRow(artistName, info, isNowPlaying)`
         - `if (index < path.lastIndex) VerticalConnectorLine()`

2. `PathNodeRow` composable:
   - Parameters: `artistName: String`, `info: BridgeArtistInfo?`, `isNowPlaying: Boolean`
   - `animateColorAsState` for border: target `colorScheme.primary` when isNowPlaying, else `Color.Transparent`, `animationSpec = tween(300)`, label `"nowPlayingBorder"`
   - `animateColorAsState` for background tint: target `colorScheme.primary.copy(alpha = 0.12f)` when isNowPlaying, else `Color.Transparent`, `animationSpec = tween(300)`, label `"nowPlayingBg"`
   - Layout `Row(fillMaxWidth, verticalAlignment = Alignment.Top)`:
     - Left border: wrap the entire Row in `Row(Modifier.fillMaxWidth().height(IntrinsicSize.Min))` to enable `fillMaxHeight` on children.
     - Border Box: `Box(Modifier.width(4.dp).fillMaxHeight().background(borderColor))`
     - Content Column: `Column(Modifier.fillMaxWidth().background(bgTint).padding(horizontal = 16.dp, vertical = 8.dp), verticalArrangement = Arrangement.spacedBy(4.dp))`:
       - Name row: `Row(verticalAlignment = CenterVertically, horizontalArrangement = Arrangement.spacedBy(4.dp))`:
         - `Text(artistName, style = titleSmall, color = colorScheme.onSurface)`
         - `AnimatedVisibility(isNowPlaying, enter = fadeIn(tween(200)), exit = fadeOut(tween(200)))`:
           - `Icon(Icons.Outlined.VolumeUp, contentDescription = "Now playing", Modifier.size(16.dp), tint = colorScheme.primary)` -- NOTE: Check if `material-icons-extended` is available. If not (Phase 4 used `painterResource(R.drawable.*)` pattern), use `painterResource(R.drawable.volume_up)` or find an existing drawable. If no volume_up drawable exists, use `Icons.Filled.PlayArrow` (available in base material-icons) as alternative.
       - Listener count: `if (info != null) Text(info.formattedListeners, style = bodySmall, color = colorScheme.onSurface.copy(alpha = 0.6f))`
       - Genre tags: `if (info != null && info.tags.isNotEmpty())`:
         - `@OptIn(ExperimentalLayoutApi::class) FlowRow(horizontalArrangement = Arrangement.spacedBy(4.dp), verticalArrangement = Arrangement.spacedBy(4.dp))`:
           - `info.tags.take(3).forEach { tag -> GenreTagChip(tag) }`
   - Accessibility: `Modifier.semantics { contentDescription = buildString { append(artistName); if (info != null) { append(", "); append(info.formattedListeners); if (info.tags.isNotEmpty()) { append(", genres: "); append(info.tags.take(3).joinToString()) } } } }` on the outer Row.

3. `GenreTagChip` composable:
   - `SuggestionChip(onClick = {}, label = { Text(tag, style = labelMedium) }, Modifier.height(24.dp), colors = SuggestionChipDefaults.suggestionChipColors(containerColor = colorScheme.primary.copy(alpha = 0.12f), labelColor = colorScheme.primary), border = null, enabled = false)`
   - If `SuggestionChip` minimum height is problematic, use a simple `Box(Modifier.height(24.dp).background(colorScheme.primary.copy(0.12f), RoundedCornerShape(12.dp)).padding(horizontal = 8.dp), contentAlignment = Center) { Text(tag, style = labelMedium, color = colorScheme.primary) }` as fallback per Research Pitfall 6.

4. `VerticalConnectorLine` composable:
   - Wrap in `Box(Modifier.fillMaxWidth())` with inner `Box(Modifier.width(4.dp).height(12.dp).align(Alignment.CenterStart).background(colorScheme.outline.copy(alpha = 0.38f)))`. The left border is at x=0 in the Row, so the connector aligns at CenterStart to connect vertically.

**Part B: Refactor BridgeScreen.kt**

Per D-01, D-02, and the UI-SPEC layout structure:

1. Wrap the existing `Column(Modifier.fillMaxSize()...)` content in a `BoxWithConstraints(Modifier.fillMaxSize())`:
   - Extract the entire existing Column content (inputs, button, state-driven section) into a private composable `BridgeSearchContent(uiState, viewModel, isBuilding, showQueueDialog, buildFailed, playerConnection)` or keep inline -- either works. The key is the Column goes first inside BoxWithConstraints, the BottomSheet goes second.

2. Add BottomSheet state and trigger:
   ```kotlin
   val pathSheetState = rememberBottomSheetState(
       dismissedBound = 0.dp,
       expandedBound = maxHeight,
       collapsedBound = 220.dp,
       initialAnchor = dismissedAnchor
   )
   ```

3. Add `LaunchedEffect(uiState)` for sheet trigger per D-02:
   ```kotlin
   LaunchedEffect(uiState) {
       when (uiState) {
           is BridgeUiState.PathFound, is BridgeUiState.PlaylistReady -> pathSheetState.collapseSoft()
           is BridgeUiState.Idle, is BridgeUiState.Searching -> pathSheetState.dismiss()
           else -> Unit  // Error state: leave sheet as-is
       }
   }
   ```

4. Add now-playing observation via `LaunchedEffect(mediaMetadata)` per D-05 and Research Pattern 3:
   ```kotlin
   val mediaMetadata by playerConnection?.mediaMetadata?.collectAsState() ?: remember { mutableStateOf(null) }
   LaunchedEffect(mediaMetadata) {
       val artistName = mediaMetadata?.artists?.firstOrNull()?.name ?: ""
       viewModel.onNowPlayingArtistChanged(artistName)
   }
   ```

5. Collect `artistMetadata` from ViewModel:
   ```kotlin
   val artistMetadata by viewModel.artistMetadata.collectAsState()
   ```

6. After the Column content, add the BottomSheet overlay:
   ```kotlin
   val path = when (val s = uiState) {
       is BridgeUiState.PathFound -> s.path
       is BridgeUiState.PlaylistReady -> s.path
       else -> null
   }
   val nowPlayingIndex = (uiState as? BridgeUiState.PlaylistReady)?.nowPlayingIndex ?: -1

   if (path != null) {
       BottomSheet(
           state = pathSheetState,
           onDismiss = { /* allow dismiss -- sheet re-openable */ },
           collapsedContent = {
               // Collapsed: compact handle with "Bridge Path" label
               Box(
                   Modifier.fillMaxWidth().height(pathSheetState.collapsedBound).padding(16.dp),
                   contentAlignment = Alignment.TopCenter
               ) {
                   // Drag handle
                   Box(
                       Modifier.width(32.dp).height(4.dp)
                           .background(MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.4f), RoundedCornerShape(2.dp))
                   )
               }
           }
       ) {
           PathSheet(
               path = path,
               artistMetadata = artistMetadata,
               nowPlayingIndex = nowPlayingIndex,
           )
       }
   }
   ```

7. Add "Show Path" button when sheet is dismissed but path exists -- place inside the Column content, after the `when(state)` block:

   if (path != null && pathSheetState.isDismissed) {

   NOTE: `path` needs to be accessible inside the Column. Compute it before the BoxWithConstraints or lift the variable.
