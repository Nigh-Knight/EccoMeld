Per D-08: Replace app icon with the EccoMuse logo. Source file: `/home/kepler/Projects/EccoMuse-Site/src/assets/images/EccoMuse_new_logo.png` (1024x1024 PNG, sRGB).

Use ImageMagick (`magick` command at `/nix/store/nlj39q92qdi1hidpkzcqi7vl2m9r7nyf-imagemagick-7.1.2-13/bin/magick`) to resize the source logo to each density bucket for the foreground layer. Android adaptive icon spec: 108dp per layer, which translates to:

- mdpi: 108x108 px
- hdpi: 162x162 px
- xhdpi: 216x216 px
- xxhdpi: 324x324 px
- xxxhdpi: 432x432 px

For each density, run:
```bash
SRC="/home/kepler/Projects/EccoMuse-Site/src/assets/images/EccoMuse_new_logo.png"
MIPMAP="/home/kepler/Projects/EccoMeld/app/src/main/res"

magick "$SRC" -resize 108x108 "$MIPMAP/mipmap-mdpi/ic_launcher_foreground.png"
magick "$SRC" -resize 162x162 "$MIPMAP/mipmap-hdpi/ic_launcher_foreground.png"
magick "$SRC" -resize 216x216 "$MIPMAP/mipmap-xhdpi/ic_launcher_foreground.png"
magick "$SRC" -resize 324x324 "$MIPMAP/mipmap-xxhdpi/ic_launcher_foreground.png"
magick "$SRC" -resize 432x432 "$MIPMAP/mipmap-xxxhdpi/ic_launcher_foreground.png"
```

For the monochrome layer (used by themed icons on Android 13+), create a grayscale version:
```bash
magick "$SRC" -colorspace Gray -resize 108x108 "$MIPMAP/mipmap-mdpi/ic_launcher_monochrome.png"
magick "$SRC" -colorspace Gray -resize 162x162 "$MIPMAP/mipmap-hdpi/ic_launcher_monochrome.png"
magick "$SRC" -colorspace Gray -resize 216x216 "$MIPMAP/mipmap-xhdpi/ic_launcher_monochrome.png"
magick "$SRC" -colorspace Gray -resize 324x324 "$MIPMAP/mipmap-xxhdpi/ic_launcher_monochrome.png"
magick "$SRC" -colorspace Gray -resize 432x432 "$MIPMAP/mipmap-xxxhdpi/ic_launcher_monochrome.png"
```

Do NOT change the background layer PNGs -- the existing solid background works. Do NOT change the adaptive icon XML files (`mipmap-anydpi/ic_launcher.xml`, `mipmap-anydpi-v31/ic_launcher.xml`) -- they already reference foreground/background/monochrome layers correctly.

Do NOT modify ic_launcher.png files (the non-adaptive fallback icons) at this time -- they are used on very old launchers. The adaptive icon is what matters for SDK 26+.
