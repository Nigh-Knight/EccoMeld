    - If both empty, return 1.0
    - `val intersection = tagsA.intersect(tagsB).size`
    - `val union = tagsA.union(tagsB).size`
    - `if (union == 0) 1.0 else intersection.toDouble() / union`

    - Filter to artists with at least 1 tag. If fewer than 2 remain, fall back to first 2 from `tagMap.keys`.
    - O(n^2) pairwise comparison, track minimum similarity pair.
    - Return pair with lowest Jaccard similarity, or null if fewer than 2 artists total.

      - On main dispatcher: set `_fromQuery.value`, `_toQuery.value`, `_fromConfirmedArtist.value`, `_toConfirmedArtist.value` to the selected pair
